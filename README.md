# Console Bank Management System

A lightweight, terminal-based banking application built entirely in C++. This project serves as a practical demonstration of foundational Object-Oriented Programming (OOP) principles, data handling, and console UI management.

## Features

* **Account Management:** Open new accounts (Savings/Current), modify existing account holder details, or safely close accounts.
* **Secure Transactions:** Process deposits and withdrawals with built-in balance validation to prevent overdrafts and negative inputs.
* **Search & View:** Retrieve specific account details instantly using a unique account number, or display a formatted list of all registered accounts.
* **Dynamic Storage:** Utilizes C++ unordered_map to manage account data dynamically in memory.
* **Cross-Platform Console:** Implements dynamic screen clearing (`cls` for Windows, `clear` for Unix) for a clean user experience.

## Tech Stack

* **Language:** C++
* **Core Concepts:** Object-Oriented Programming (Classes, Encapsulation), Standard Template Library.
